**Movehat** is a Hardhat-like development framework for [**Movement L1**](https://movementnetwork.xyz/). Write tests and deployment scripts in TypeScript against a real local blockchain, a read-only fork of a remote network, or a live testnet / mainnet — all behind a single Hardhat-style harness.

## At a glance

Three execution modes cover the spectrum from unit tests to production deployments. Each mode is constructed via a static factory on `Harness`; the returned instance shares the same surface, so test code is portable across modes.

<Tabs items={['Local', 'Fork', 'Live']}>
<Tab value="Local">

Spawns a real Movement local node, funds the labeled accounts from the local faucet, and (when `autoDeploy` is set) publishes the named modules. Best for integration tests with real transaction flow.

```typescript
import { Harness } from "movehat";

const harness = await Harness.createLocal({
  accountLabels: ["deployer", "alice"],
  autoDeploy: ["counter"],
});

const counter = harness.runtime.getContract(
  harness.runtime.getDeploymentAddress("counter"),
  "counter"
);
await counter.call(harness.runtime.account, "increment", []);
await harness.cleanup();
```

</Tab>
<Tab value="Fork">

Reads from a JSON-backed local snapshot of a remote network. Resources lazy-load as you read them. Best for testing against real testnet / mainnet state without deploying.

```typescript
import { Harness } from "movehat";

const harness = await Harness.createFork("testnet");

const [supply] = await harness.runViewFunction({
  function: "0x1::coin::CoinInfo::supply",
  typeArguments: ["0x1::aptos_coin::AptosCoin"],
});

await harness.cleanup();
```

</Tab>
<Tab value="Live">

Binds to a real running network. No local process spawned; transactions hit the configured RPC. Best for deployment scripts and real-network interactions.

```typescript
import { Harness } from "movehat";

const harness = await Harness.createLive("testnet");

const deployment = await harness.deployCodeObject({
  moduleName: "counter",
});
console.log(`Deployed: ${deployment.address}::counter`);

await harness.cleanup();
```

</Tab>
</Tabs>

<Callout type="info">
  `Harness.cleanup()` poisons the instance: any further call to a deploy / view / script method throws `HarnessDisposedError` synchronously. Lifecycle errors fail loud instead of silently using a stale handle.
</Callout>

## Why Movehat?

|                            | Movehat              | Hardhat            | Foundry            |
|----------------------------|----------------------|--------------------|--------------------|
| **Language**               | Move + TypeScript    | Solidity + TS/JS   | Solidity           |
| **Local blockchain**       | Built-in             | Built-in           | Built-in (anvil)   |
| **Fast local boot**        | movelite (sub-second)| Built-in           | Built-in (anvil)   |
| **Fork system**            | Built-in JSON        | External           | Built-in           |
| **Auto-detected addresses**| Yes                  | N/A                | Manual             |
| **Execution traces**       | `-vvvv` (full tree on movelite) | Plugin  | `-vvvv` built-in   |
