## Usage

```bash
movehat test [options]
```

Run tests with an interactive menu or flags. With no flags, Movehat shows the
menu in a terminal and runs `--all` automatically when stdin/stdout are not a
TTY, so CI never waits for a prompt.

## Options

| Flag | Description |
|------|-------------|
| `--move` | Run only Move unit tests (fast, no node required) |
| `--ts` | Run only TypeScript integration tests (starts local node) |
| `--all` | Run all tests (Move + TypeScript) |
| `--watch` | Run TypeScript tests in watch mode (implies `--ts`) |
| `--coverage` | Run Move tests with coverage, then print the Movement CLI summary |
| `--filter <pattern>` | Filter Move tests by pattern |

> Shorthand commands like `movehat test:move` forward additional flags to the underlying runner. For example, `movehat test:move --ignore-warnings` is valid and forwards `--ignore-warnings` to the Move test runner.

## Interactive Menu

When you run `movehat test` without flags:

```
? What tests do you want to run?
❯ Move unit tests (fast, no node required)
  TypeScript integration tests (starts local node)
  All tests (Move + TypeScript)
```

## Examples

```bash
# Interactive menu
movehat test

# Run only Move tests (ultra-fast)
movehat test --move

# Run only TypeScript tests
movehat test --ts

# Run all tests
movehat test --all

# Run Move coverage and print its summary
movehat test --coverage

# Watch mode for TypeScript tests
movehat test --watch

# Filter Move tests by pattern
movehat test --move --filter test_increment
```

## Shorthand Commands

```bash
# Run only Move unit tests
movehat test:move

# Run only Move tests with filter
movehat test:move --filter test_inc

# Ignore compilation warnings
movehat test:move --ignore-warnings

# Run only TypeScript tests
movehat test:ts

# Watch mode
movehat test:ts --watch
```
