## Lint

```bash
movehat lint
```

Runs `movement move lint` for the package configured by `moveDir`, resolving
named addresses through the package's `[dev-addresses]` (the same `--dev`
resolution `movehat test --move` uses), so the scaffold's `_` placeholder
addresses lint without extra configuration. Lint is a finite command and
Movehat stops it if it exceeds five minutes.

The Movement CLI linter exits non-zero when it reports warnings, so a clean
run means warning-free code.

## Prove

```bash
movehat prove
```

Runs `movement move prove` for the configured package. Proving can legitimately
take much longer than compilation, so Movehat does not impose a timeout. It runs
until the prover finishes or you press Ctrl+C.

Both commands pass the package path as a direct process argument, including
paths that contain spaces, rather than evaluating it through a shell.
