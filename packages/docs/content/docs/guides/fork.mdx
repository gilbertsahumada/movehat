MoveHat includes a native fork system that creates local snapshots of Movement L1 network state. Unlike traditional forks, MoveHat's fork system:

- Uses JSON API (no BCS compatibility issues)
- Works natively with Movement L1
- Implements lazy loading (only fetches accessed resources)
- Provides clean CLI and programmatic API
- Stores state as human-readable JSON

## Quick Start

### Create a Fork

```bash
movehat fork create --network testnet --name my-fork
```

This creates a fork snapshot at the current ledger version.

### View Resources

```bash
movehat fork view-resource \
  --fork .movehat/forks/my-fork \
  --account 0x1 \
  --resource "0x1::coin::CoinInfo<0x1::aptos_coin::AptosCoin>"
```

First access fetches from network and caches locally. Subsequent accesses use the cache.

### Fund Accounts

```bash
movehat fork fund \
  --fork .movehat/forks/my-fork \
  --account 0x123 \
  --amount 5000000000
```

### List Forks

```bash
movehat fork list
```

### Serve Fork via RPC

```bash
movehat fork serve --fork .movehat/forks/my-fork --port 8080
```

This starts a local RPC server that serves the fork. Connect any Movement-compatible TypeScript SDK to `http://localhost:8080/v1`.

**Supported endpoints:**
- `GET /v1/` — Ledger info (chain ID, version, block height)
- `GET /v1/accounts/:address` — Account data
- `GET /v1/accounts/:address/resource/:type` — Specific resource
- `GET /v1/accounts/:address/resources` — All resources for an account

## Programmatic API

### Basic Usage

```typescript
import { ForkManager } from 'movehat';

const fork = new ForkManager('.movehat/forks/test');
await fork.initialize('https://testnet.movementnetwork.xyz/v1', 'testnet');

const metadata = fork.getMetadata();
console.log(`Fork at version: ${metadata.ledgerVersion}`);

const coinInfo = await fork.getResource(
  '0x1',
  '0x1::coin::CoinInfo<0x1::aptos_coin::AptosCoin>'
);
console.log(`Token name: ${coinInfo.name}`);
```

### Testing Example

```typescript
import { describe, it, before } from 'mocha';
import { expect } from 'chai';
import { ForkManager } from 'movehat';

describe('My Contract Tests', () => {
  let fork: ForkManager;

  before(async () => {
    fork = new ForkManager('.movehat/forks/test');
    await fork.initialize('https://testnet.movementnetwork.xyz/v1', 'testnet');
  });

  it('should read token info from fork', async () => {
    const coinInfo = await fork.getResource(
      '0x1',
      '0x1::coin::CoinInfo<0x1::aptos_coin::AptosCoin>'
    );

    expect(coinInfo.name).to.equal('Move Coin');
    expect(coinInfo.symbol).to.equal('MOVE');
    expect(coinInfo.decimals).to.equal(8);
  });

  it('should fund and verify account balance', async () => {
    await fork.fundAccount('0x123', 5_000_000_000);

    const coinStore = await fork.getResource(
      '0x123',
      '0x1::coin::CoinStore<0x1::aptos_coin::AptosCoin>'
    );

    expect(coinStore.coin.value).to.equal('5000000000');
  });

  it('should modify fork state without affecting network', async () => {
    const testAccount = '0xABC';

    await fork.fundAccount(testAccount, 1_000_000);

    const coinStore = await fork.getResource(
      testAccount,
      '0x1::coin::CoinStore<0x1::aptos_coin::AptosCoin>'
    );
    coinStore.coin.value = '2000000';

    await fork.setResource(
      testAccount,
      '0x1::coin::CoinStore<0x1::aptos_coin::AptosCoin>',
      coinStore
    );

    const updated = await fork.getResource(
      testAccount,
      '0x1::coin::CoinStore<0x1::aptos_coin::AptosCoin>'
    );
    expect(updated.coin.value).to.equal('2000000');
  });
});
```

### Loading an Existing Fork

```typescript
import { ForkManager } from 'movehat';

const fork = new ForkManager('.movehat/forks/my-fork');
fork.load();

const metadata = fork.getMetadata();
console.log(`Forked from: ${metadata.network}`);
console.log(`Chain ID: ${metadata.chainId}`);
```

### Snapshot replacement and long-running processes

Each `ForkManager` stays pinned to the snapshot generation it loaded. If
another process overwrites or resets the same fork directory, the older
manager throws `ForkSnapshotChangedError` instead of reading or modifying the
replacement snapshot:

```typescript
import { ForkManager, ForkSnapshotChangedError } from 'movehat';

try {
  await fork.getResource('0x1', '0x1::example::Resource');
} catch (error) {
  if (error instanceof ForkSnapshotChangedError) {
    fork.load(); // Explicitly adopt the current on-disk snapshot.
  } else {
    throw error;
  }
}
```

`movehat fork serve` responds with HTTP `409` and
`fork_snapshot_changed` after its fork is replaced. Restart the server to load
the new snapshot. MoveHat never switches snapshots silently inside a running
manager or server.

If an overwrite is interrupted, reads remain blocked rather than accepting
partially-cleared state. Run `movehat fork create` for the same destination and
confirm the overwrite to recover it.

## Fork Storage Structure

Forks are stored as JSON files for easy inspection and version control:

```
.movehat/forks/
  my-fork/
    metadata.json           # Network info, ledger version
    accounts.json           # Account states
    resources/              # Resource data by account
      0x1.json
      0xABC123.json
    cache/
      .gitignore
```

### Example Files

**metadata.json:**

```json
{
  "network": "testnet",
  "nodeUrl": "https://testnet.movementnetwork.xyz/v1",
  "chainId": 250,
  "ledgerVersion": "49825529",
  "timestamp": "1765402199957937",
  "epoch": "2112090",
  "blockHeight": "15097075",
  "createdAt": "2025-12-10T21:48:22.123Z"
}
```

## API Reference

### ForkManager

#### Constructor

```typescript
new ForkManager(forkPath: string)
```

#### Methods

| Method | Description |
|--------|-------------|
| `initialize(nodeUrl, networkName?)` | Initialize a new fork from a network |
| `load()` | Load an existing fork from disk |
| `getMetadata()` | Get fork metadata |
| `getResource(address, resourceType)` | Get a resource with lazy loading |
| `getAllResources(address)` | Get all resources for an account |
| `setResource(address, resourceType, data)` | Set/update a resource value |
| `fundAccount(address, amount, coinType?)` | Fund an account with coins |
| `listAccounts()` | List all accounts in the fork |

## How It Works

### Lazy Loading

1. **Fork Creation**: Only fetches network metadata
2. **Resource Access**: Fetches resources on-demand when first accessed
3. **Caching**: Stores fetched resources locally
4. **Modification**: Modified resources are saved immediately

### JSON vs BCS

MoveHat uses JSON API instead of BCS:

| Feature | MoveHat Forks | Stock CLI Sim |
|---------|---------------|---------------|
| Works with Movement | Yes | BCS incompatible |
| JSON-based | Yes | BCS only |
| Lazy loading | Yes | Downloads all |
| Human-readable | Yes | Binary |
| Programmatic API | Clean API | Limited |
| Test-friendly | Very | Complex |

## Best Practices

### One Fork Per Test Suite

```typescript
describe('Token Tests', () => {
  let fork: ForkManager;

  before(async () => {
    const networkUrl = 'https://testnet.movementnetwork.xyz/v1';
    fork = new ForkManager('.movehat/forks/token-tests');
    await fork.initialize(networkUrl, 'testnet');
  });
});
```

### Clean Forks for Each Run

```bash
rm -rf .movehat/forks/test-*
```

### Version Control

Add to `.gitignore`:

```
.movehat/forks/*/cache/
```

But **commit** metadata and resources for reproducible tests.

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Fork creation fails | Check network URL and verify network is accessible |
| Resource not found (404) | Verify account address exists and resource type is exact |
| Fork snapshot changed (409) | Call `load()` on programmatic managers or restart `movehat fork serve` |
| Port already in use | Use a different port: `--port 8081` |
| Permission denied | Use a port above 1024 |
