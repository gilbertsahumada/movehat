## Prerequisites

Before installing Movehat, make sure you have:

- **Node.js** (v20 or later) — [Download](https://nodejs.org/)
- **Movement CLI** — **REQUIRED** for compiling and deploying Move contracts

### Install Movement CLI

Follow the official guide: [Movement CLI Installation Guide](https://docs.movementnetwork.xyz/devs/movementcli)

Verify installation:

```bash
movement --version
```

**Without Movement CLI installed, compilation will fail with:**

```
Compilation failed: Command failed: movement move build
/bin/sh: movement: command not found
```

## Install Movehat

```bash
npm install -g movehat
# or
pnpm install -g movehat
```

On supported platforms (macOS arm64/x64, Linux x64/arm64), this also pulls a
`movelite` binary as an optional dependency, used for fast local-test boot.
Nothing to install or configure: movehat uses it automatically when present
and falls back to the full Movement node otherwise, including on platforms
where the binary is not available. See
[Fast local boot with movelite](/docs/guides/testing#fast-local-boot-with-movelite-optional).

## System Requirements

**Required:**
- Node.js v20+
- Movement CLI ([install from Movement docs](https://docs.movementnetwork.xyz/devs/movementcli))
- npm or pnpm

**Recommended:**
- Git (for version control)
- VS Code with Move syntax highlighting extension

## Verify Installation

```bash
movehat --version
```
