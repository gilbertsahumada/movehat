## Create Your First Project

```bash
# 1. Create project
npx movehat init my-project
cd my-project

# 2. Install dependencies
npm install

# 3. Compile contracts (auto-detects addresses)
npx movehat compile

# 4. Run tests (uses simulation — no setup needed)
npm test
```

Done! Your tests run against a local Movement node started by Movehat.

## What Just Happened?

## Testing Workflow

Movehat provides **two types of tests** for comprehensive coverage:

### Move Unit Tests (Fast)

Tests written directly in your Move files:

```move
#[test(account = @0x1)]
public fun test_increment(account: &signer) acquires Counter {
    let addr = signer::address_of(account);
    aptos_framework::account::create_account_for_test(addr);

    init(account);
    assert!(get(addr) == 0, 0);

    increment(account);
    assert!(get(addr) == 1, 1);
}
```

Run with: `movehat test --move` (ultra-fast, milliseconds)

### TypeScript Integration Tests (Local Node)

Tests written in TypeScript that run on a **local Movement blockchain** using the Hardhat-style `Harness` API:

```typescript
import { Harness } from "movehat";

describe("Counter Contract", () => {
  let harness;
  let counter, deployer;

  before(async function () {
    this.timeout(60000);
    // Starts local node, funds accounts, deploys the named module(s)
    harness = await Harness.createLocal({
      accountLabels: ["deployer", "alice", "bob"],
      autoDeploy: ["counter"],
    });
    deployer = harness.accounts.deployer;
    const addr = harness.runtime.getDeploymentAddress("counter");
    counter = harness.runtime.getContract(addr, "counter");
  });

  it("should increment counter", async () => {
    await counter.call(deployer, "increment", []);

    const [value] = await harness.runViewFunction({
      function: `${counter.moduleAddress}::counter::get`,
      functionArguments: [deployer.accountAddress.toString()],
    });

    expect(parseInt(value)).to.equal(1);
  });

  after(async () => {
    // Stops the local node and poisons the harness — any further
    // method call (other than cleanup) throws HarnessDisposedError.
    await harness.cleanup();
  });
});
```

> **Looking for the older API?** `setupTestFixture` / `teardownTestFixture` still works (see `movehat/helpers`); use whichever style fits your codebase. `Harness` is the primary surface.

Run with: `movehat test --ts` (starts local node)

## Ready to Deploy?

For real deployment to Movement testnet/mainnet:

1. **Set up your private key:**

   ```bash
   cp .env.example .env
   ```

2. **Edit `.env`:**

   ```bash
   PRIVATE_KEY=0x<YOUR_PRIVATE_KEY>
   ```

3. **Deploy:**

   ```bash
   npx movehat run scripts/deploy-counter.ts --network testnet
   ```

## Common Commands

```bash
# Compile contracts
npx movehat compile

# Run tests (interactive menu)
npm test

# Run only Move tests (ultra-fast)
movehat test --move

# Run only TypeScript tests (starts local node)
movehat test --ts

# Run all tests
movehat test --all

# Run TypeScript tests in watch mode
movehat test --watch

# Filter Move tests
movehat test --move --filter test_increment

# Deploy to testnet (explicit flag avoids relying on default network)
npx movehat run scripts/deploy-counter.ts --network testnet

# Deploy to mainnet
npx movehat run scripts/deploy-counter.ts --network mainnet
```
