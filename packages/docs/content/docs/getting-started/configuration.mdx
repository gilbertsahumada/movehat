## Network Configuration

Edit `movehat.config.ts` to configure your networks:

```typescript
import dotenv from "dotenv";
dotenv.config();

export default {
  // Default network to use when no --network flag is provided
  defaultNetwork: "local",

  // Network configurations
  networks: {
    testnet: {
      url: process.env.MOVEMENT_RPC_URL || "https://testnet.movementnetwork.xyz/v1",
      chainId: "testnet",
    },
    mainnet: {
      url: "https://mainnet.movementnetwork.xyz/v1",
      chainId: "mainnet",
    },
    local: {
      url: "http://localhost:8080/v1",
      chainId: "local",
    },
  },

  // Global accounts configuration (Hardhat-style)
  accounts: process.env.PRIVATE_KEY ? [process.env.PRIVATE_KEY] : [],

  // Move source directory
  moveDir: "./move",

  // Named addresses (optional — auto-detected from Move files)
  namedAddresses: {
    // Example: counter: "0x1234...",
  },
};
```

### Key Design Decisions

- **Explicit public signing** — Testnet and mainnet transactions use your
  configured account; Movehat never injects its deterministic development key
- **Credential-free local default** — Loopback local/movelite networks receive
  a deterministic development account automatically
- **Flexible** — You can still specify different accounts per network if needed

## Environment Variables

```bash
# Required only for public-network transactions
PRIVATE_KEY=0x<YOUR_PRIVATE_KEY>

# Optional: Override RPC URL or default network
MOVEMENT_RPC_URL=https://custom-testnet.movementnetwork.xyz/v1
MH_DEFAULT_NETWORK=mainnet
```

### Account Resolution Order

Movehat looks for accounts in this order:

1. Network-specific `accounts` in config
2. Global `accounts` in config
3. `PRIVATE_KEY` env variable

## Environment Setup

**For local testing only?** Skip environment setup. Local/movelite tests use
safe deterministic development accounts; public networks never do.

**For real deployment?** Configure your private key:

```bash
cp .env.example .env
```

Edit `.env`:

```bash
PRIVATE_KEY=0x<YOUR_PRIVATE_KEY>
```

**Security notes:**
- Public testnet and mainnet transactions require an explicit `PRIVATE_KEY`
- Local tests automatically use safe development accounts (no configuration needed)

## Network Options

| Network | Description |
|---------|-------------|
| `testnet` | Movement testnet; built-in RPC, select explicitly and configure credentials for transactions |
| `mainnet` | Movement mainnet; explicit config and credentials required |
| `local` (default) | Self-contained loopback chain; deterministic local account allowed |

## Using Multiple Accounts

```typescript
// movehat.config.ts
export default {
  accounts: [
    process.env.PRIVATE_KEY,     // Primary (harness.runtime.account)
    process.env.SECONDARY_KEY,   // harness.runtime.accounts[1]
  ].filter(Boolean),
};

// In your script
import { Harness } from "movehat";

const harness = await Harness.createLive("testnet");
try {
  const primaryAccount = harness.runtime.account;                  // accounts[0]
  const secondaryAccount = harness.runtime.getAccountByIndex(1);   // accounts[1]
  // ...
} finally {
  await harness.cleanup();
}
```
